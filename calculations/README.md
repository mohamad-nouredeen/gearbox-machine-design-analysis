# Supporting Calculations

This folder contains the handwritten engineering calculations developed during the gearbox design and verification process.

The notes include:

- Gear torque and force calculations
- Shaft reaction-force calculations
- Internal force and bending-moment analysis
- Torsional loading
- Static stress calculations
- Fatigue analysis and Haigh-diagram calculations
- Gear bending and contact calculations
- Bearing load, life, and static safety calculations

These notes are provided as supporting working material. The final project report in the `report/` directory should be considered the authoritative source for the final results.
