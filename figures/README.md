# Figures

This folder contains selected figures from the gearbox machine design analysis.

The figures are used to illustrate the main engineering calculations and verification results presented in the project report.

Planned figures include:

- Shaft internal force and bending-moment diagrams
- Haigh fatigue diagrams
- Gear fatigue and geometry-factor charts
- Bearing life and lubricant-selection charts
- Summary tables of key calculation results
